# Factory Controller Mod for Satisfactory
Tired of configuring each smelter or constructor individually in your massive factories? This mod introduces a centralized Factory Control Unit, allowing you to manage entire production lines from a single interface.

## Key Features
### Centralized Control:
Place the Control Unit and connect it to nearby production buildings.

### Mass Recipe Management:
Select a recipe once (e.g., "Iron Ingot") and apply it to all connected smelters or constructors instantly.

### Scalable Design:
Perfect for managing "blueprint" factories, allowing you to quickly reconvert a section for different resources.

### Master Power Switch(*):
Cut or restore power to your entire controlled factory section with one click, helping with load balancing or troubleshooting.
